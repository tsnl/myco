# Evaluations

<aside class="status-note"><strong>Work in progress.</strong> This section reserves a place for Myco's evaluation workflow. A dedicated eval runner and its user-facing API are not available on <code>main</code> yet.</aside>

The existing libraries provide useful foundations: a supplied `GenerativeModel`,
an environment implemented as `ToolExecutor`, explicit input/context, and
headless `Agent::run`. See the [agent API](agents.md) for those current contracts.

Future documentation belongs here for defining cases and environments, running
suites, recording outcomes, and interpreting results. Those interfaces will be
documented when the feature takes shape; no eval commands or file formats are
promised by this page.
